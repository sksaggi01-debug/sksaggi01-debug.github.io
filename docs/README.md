## Contents

| Folder | What it holds |
|---|---|
| `work-samples/` | One detailed sample per assignment type: Mercor task authoring, pairwise text and pairwise image evaluation; Snorkel benchmark question with peer review, and LLM response review with adjudication. |
| `ai-evaluation/` | Original sample problems with planted traps, and an annotated review of a model response. No client items. |
| `games/econ-arcade/` | Ten multiplayer macro games (ECON 2301) with an instructor guide and a network connection test. |
| `games/` | Cedar Flats Money Machine, Market Movers, Elasticity Lab, Oligopoly Payoff Matrix. |
| `lessons/` | Elasticity Live Deck, Cedar Flats GDP Audit, Farmer Jane case study, Wheat Farm Simulator, Perfect Competition vs Monopoly, Microsoft Monopoly case, Movement or Shift?, Micro Exam 1 Practice Set. |

Every file is self-contained HTML and runs in a browser with no login.
