10 games

Econ Arcade

Browser games for ACC Principles of Macroeconomics. No downloads, no accounts, phone or laptop. Each game runs about 10 minutes including the debrief.

How students play

One student presses Create a room and reads out the 4-letter code. Everyone else types it in. Everyone gets the identical rounds in the same order, and scores update live. If the network blocks the relay, Pass-and-play works on a single shared device.

Read the instructor guide

Run the connection test on campus wifi before you use these in class.
