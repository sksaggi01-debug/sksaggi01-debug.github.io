Instructor guide

Econ Arcade — how to run these in class

Ten browser games for Principles of Macroeconomics. Each is built for a 10-minute block: about a minute to get everyone in, four to five minutes of play, and three to four minutes of debrief — which is where most of the learning actually happens.

The 60-second version

Post the .html file in Blackboard as a content item. Students click it, type a name, and either create a room (they read the 4-letter code aloud) or join with that code. Everyone gets the identical rounds in the same order, and the live scoreboard updates as they play. No downloads, no accounts, no logins — works on any phone or laptop.

Before the first time you use these

Open connection-test.html on the campus wifi you will actually be teaching on, on two devices. It tells you in about five seconds whether the live relay works there.

If it is blocked — some campus networks filter it — nothing breaks. Every game has a Pass-and-play button on the first screen: two to four students share one device, each plays the same set of rounds in turn, and the app compares their scores at the end. Pair work, zero network. Plan for pairs and you are safe either way.

Running a round

0:00 Post the link, say the room code out loud1 min
1:00 Anyone presses Start — play4–5 min
6:00 Put the winner's screen up, run the debrief questions3–4 min

The debrief questions are printed on the results screen of every game, so students see them at the same moment you do. The single highest-value question is almost always: "Which round split the room, and why?"

The seven quiz games draw 8 rounds from a bank of 12, so a second play in the same room code gives a different mix. The three marked sim are multi-turn decision games and are the ones worth 12–15 minutes if you have the room.

What the sims are secretly teaching

Growth Engine. Pure strategies lose. All-consumption ends up poor; all-capital hits diminishing returns and never enjoys anything. The winners balance, and technology only pays off if education came first — which is the point.

Fiscal Fix. Doing nothing scores about 400. Overspending scores under 100. A well-judged $300–400B in year one scores over 900. Students discover the lag problem by overshooting into inflation.

Fed Chair Faceoff. Starts at 5.5% inflation. A 6% nominal rate feels aggressive but is loose in real terms — most students learn this the hard way in quarter two. The scoring floor is set so that even a perfect path cannot avoid some unemployment: that unavoidable cost is the sacrifice ratio, and it makes for a good closing discussion.

Grading, if you want to

Nothing is recorded anywhere — no accounts means no gradebook. If you want participation credit, have students screenshot their results screen and drop it in a Blackboard assignment, or simply record the top three each round on paper. The games are designed as formative practice, not assessment.
